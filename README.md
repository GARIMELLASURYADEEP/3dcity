# City Engine

Installation

```bash
npm install
npm run dev
```

Controls

- Click to lock pointer and use WASD to move.
- Mouse to look around in pointer mode.
- Use GUI toggles (top-right) to enable/disable traffic, pedestrians, and adjust time of day.

Notes

- Run at `http://localhost:5173` when using `npm run dev`.
- Assets and DRACO decoder should be placed in `public/` if used.
